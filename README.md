# VtM_LoCh_fP

### Vampire: The Masquerade — V20 Character Sheet

**Интерактивный лист персонажа для Vampire: The Masquerade 20th Anniversary Edition (V20).**

VtM_LoCh_fP — настольное Windows-приложение, предназначенное для создания, редактирования и ведения персонажей Vampire: The Masquerade V20.

Приложение объединяет инструменты управления характеристиками, способностями, преимуществами, дисциплинами, ресурсами, историей и снаряжением персонажа. Автоматические расчёты и учёт игровых расходов позволяют уделять больше внимания самой игре, а не ручному заполнению листа.

## Возможности

### Управление персонажами

- Создание нескольких персонажей.
- Переключение между персонажами.
- Индивидуальные файлы сохранения.
- Редактирование основной информации персонажа.
- Создание независимых копий персонажей.
- Импорт и экспорт персонажей.
- Автоматическое сохранение изменений.
- Защита повреждённых файлов сохранений от случайной перезаписи.

### Создание персонажа

Доступны два режима создания персонажа:

- **Свободный Неонат** — создание персонажа с использованием стандартной системы распределения характеристик, но со способностью к гибким изменениями под нужды игрока.
- **Птенец на поводке Сира** — создание персонажа по жёсткой стандартной системе с правилами распределения, ограничения и развития прямиком из книги.

Также доступен генератор персонажей, позволяющий создать за два клика, полностью готового и сбалансированного персонажа

Возможности генератора:
- Распределение характеристик.
- Работа со способностями.
- Выбор преимуществ.
- Покупка достоинств и недостатков за свободные очки.
- Учёт правил создания персонажа.
- Написание предысторий
- Заполнение снаряжения

## Системные требования

### Для запуска

- Операционная система Windows 7 и выше.
- .NET Framework 4.8.

Если .NET Framework 4.8 отсутствует в системе, его можно установить с официального сайта Microsoft.

### Для разработки и сборки

- Visual Studio 2022 или совместимая версия.
- Компонент разработки классических приложений .NET.
- .NET Framework 4.8 Developer Pack / Targeting Pack.

### Для запуска тестов

Отдельный проект `tests` использует .NET 9 SDK.

Это требование относится только к тестовому проекту и не требуется для запуска основного приложения.

## Установка

1. Перейдите в раздел [Releases](https://github.com/taran700/VtM_LoCh_fP/releases).
2. Выберите последнюю опубликованную версию.
3. Откройте список Assets.
4. Скачайте установщик или архив приложения.
5. Запустите установщик либо распакуйте архив в удобную папку.
6. Запустите `VtM_LoCh_fP.exe`.

**Важно:** не запускайте приложение непосредственно из ZIP-архива. Сначала распакуйте его.

При первом запуске приложение автоматически создаст необходимые каталоги для пользовательских данных.

## Обновление

Приложение поддерживает автоматическую проверку обновлений через GitHub Releases.

При открытии меню персонажей выполняется проверка опубликованной версии.

Если обнаружена новая версия, в меню появляется кнопка **«Обновить»**.

Для обновления:

1. Откройте приложение.
2. Перейдите в меню персонажей.
3. Дождитесь проверки обновлений.
4. Если доступна новая версия, нажмите кнопку «Обновить».
5. Ознакомьтесь с информацией об обновлении и подтвердите установку.
6. Дождитесь завершения процесса.

Также обновление можно выполнить вручную, скачав новую версию из раздела [Releases](https://github.com/taran700/VtM_LoCh_fP/releases).

### Информация для публикации обновлений

Для корректной работы EZ_Updater необходимо соблюдать следующие условия:

- Публиковать обновления в GitHub Releases.
- Использовать тег релиза с номером версии, например `v1.0.5`.
- Прикладывать ZIP-архив приложения с постоянным именем `VtM_LoCh_fP.zip`.
- Не добавлять номер версии в имя этого ZIP-архива.

Сетевые запросы приложения используют TLS 1.2.

## Хранение данных

Пользовательские данные хранятся отдельно от каталога установки приложения.

### Персонажи

Каталог:

```text
Документы/VtM_LoCh_fP/
```

Каждый персонаж сохраняется в отдельном JSON-файле:

```text
character_<id>.json
```

Файлы персонажей содержат индивидуальные данные соответствующих персонажей.

### Настройки приложения

Настройки хранятся отдельно в XML-файле:

```text
%AppData%/VtM_LoCh_fP/settings.xml
```

В настройках сохраняются параметры оформления, игровые настройки и информация, связанная с проверкой обновлений.

### Резервное копирование

Рекомендуется периодически создавать резервные копии каталога:

```text
Документы/VtM_LoCh_fP/
```

При необходимости также сохраните:

```text
%AppData%/VtM_LoCh_fP/
```

**Важно:** не изменяйте структуру файлов сохранений вручную и не удаляйте их без необходимости.


Для запуска проверок необходимо установить .NET 9 SDK.

Тесты проверяют отдельные элементы логики игровых треков. Они не заменяют полноценную проверку интерфейса и сборки WPF-приложения.

## Сборка из исходного кода

1. Клонируйте репозиторий:

```bash
git clone https://github.com/taran700/VtM_LoCh_fP.git
```

2. Откройте файл `VtM_LoCh_fP.sln` в Visual Studio.
3. Убедитесь, что установлен .NET Framework 4.8 Developer Pack.
4. Выберите конфигурацию `Release`.
5. Выберите платформу `Any CPU`.
6. Выполните команду **Build → Build Solution**.

После успешной сборки исполняемый файл будет находиться в каталоге:

```text
VtM_LoCh_fP/bin/Release/VtM_LoCh_fP.exe
```
