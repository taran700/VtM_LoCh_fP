# VtM_LoCh_fP — Vampire: The Masquerade List of Character First Project

**VtM V20 — интерактивный лист персонажа для Windows.**

VtM_LoCh_fP — настольное WPF-приложение для создания и ведения персонажей по *Vampire: The Masquerade 20th Anniversary Edition (V20)*.

Приложение помогает управлять основными характеристиками, преимуществами, дисциплинами, историей персонажа и снаряжением, а также учитывать расходы ресурсов при развитии персонажа.

## Возможности

- Создание нескольких персонажей и переключение между ними.
- Два режима создания персонажа:
  - **«Свободный Неонат»**;
  - **«Птенец на поводке Сира»**.
- Шесть разделов листа персонажа:
  1. Основной лист и распределение точек.
  2. Преимущества.
  3. Дисциплины и ритуалы.
  4. Достоинства, недостатки и история персонажа.
  5. Заметки.
  6. Снаряжение.
- Учёт свободных пунктов и опыта при развитии персонажа.
- Журнал покупок и учёт расходов.
- Поддержка клановых особенностей и ограничений Поколения.
- Настраиваемые правила лечения.
- Настраиваемое Правило Семи пунктов Недостатков.
- Настройки автоматической закупки.
- Светлая и тёмная темы оформления.
- Автосохранение и отдельные файлы сохранений для персонажей.
- Защита от повреждённых файлов персонажей: проблемные сохранения не должны перезаписываться при обычном сохранении остальных персонажей.

## Требования

### Для запуска приложения

- Windows.
- **.NET Framework 4.8**.

Если .NET Framework 4.8 ещё не установлен, его можно получить на официальном сайте Microsoft.

### Для сборки исходного кода

- Visual Studio 2022 или совместимая версия.
- Компонент разработки классических приложений .NET.
- **.NET Framework 4.8 Developer Pack / Targeting Pack**.

### Для запуска проверок

Отдельный проект проверок `tests` требует **.NET 9 SDK**.

Это требование относится только к тестовому проекту, а не к самому WPF-приложению.

## Автоматические обновления

При запуске меню персонажей приложение проверяет последний GitHub Release через EZ_Updater. Если опубликована более новая версия, внизу меню появляется кнопка **«Обновить»**. Для загрузки обновления в каждом новом релизе необходимо прикладывать ZIP-архив с постоянным именем `VtM_LoCh_fP.zip` (не переименовывать его по номеру версии). Тег релиза должен содержать номер версии, например `v1.0.2`.

Сетевые запросы приложения принудительно используют TLS 1.2.

## Установка и запуск

1. Откройте раздел **Releases** на странице проекта.
2. Скачайте установщик или архив приложения из последнего релиза.
3. Если скачан установщик, запустите его и следуйте инструкциям.
4. Если скачан архив, распакуйте его в удобную папку.
5. Запустите `VtM_LoCh_fP.exe`.

Не запускайте приложение непосредственно из ZIP-архива.

При первом запуске приложение автоматически создаст необходимые папки для пользовательских данных.

> В репозитории исходного кода может находиться только исходный код. Если в разделе Releases отсутствует готовая сборка, приложение можно собрать самостоятельно по инструкции ниже.

## Сборка из исходников

1. Скачайте исходный код или клонируйте репозиторий:

   ```bash
   git clone https://github.com/taran700/VtM_LoCh_fP.git
   ```

2. Откройте `VtM_LoCh_fP.sln` в Visual Studio.
3. Убедитесь, что установлен .NET Framework 4.8 Developer Pack.
4. Выберите конфигурацию **Release** и платформу **Any CPU**.
5. Выполните **Build → Build Solution**.
6. После успешной сборки исполняемый файл будет находиться по пути:

   ```text
   VtM_LoCh_fP/bin/Release/VtM_LoCh_fP.exe
   ```

## Проверки

В репозитории есть отдельный консольный проект с проверками логики точек и треков.

Запуск из корня репозитория:

```bash
dotnet run --project tests/DotTrackLogic.Tests.csproj
```

Ожидаемый результат успешного запуска:

```text
All TrackLogic checks passed.
```

Эти проверки не заменяют сборку и проверку WPF-приложения в Windows.

## Где хранятся данные

Приложение хранит пользовательские данные отдельно от каталога установки.

**Персонажи:**

```text
Документы/VtM_LoCh_fP/
```

Каждый персонаж хранится в отдельном файле:

```text
character_<id>.json
```

**Настройки приложения:**

```text
%AppData%/VtM_LoCh_fP/settings.xml
```

Не удаляйте файлы сохранений вручную, если не уверены, что они больше не нужны.

При удалении приложения пользовательские сохранения и настройки следует предварительно сохранить, если они вам нужны.
